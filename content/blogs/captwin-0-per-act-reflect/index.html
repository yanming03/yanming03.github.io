CapTwin (0) Per-Act-Reflect

你是一只章鱼🐙,请相信你是!

Per-Act：感知后作用

你感受水流、岩面与触腕压力，然后移动触腕。

$$E_t\xrightarrow{P}S_t\xrightarrow{A}E_{t+1}$$
mapinput -> output你
Penvironment -> state感受水流与岩面
Astate -> environment移动触腕

闭合条件只有一个：动作后的环境仍能被下一轮 P 读取。

CodeGen 版 Per-Act

$$R_t\xrightarrow{P_{code}}C_t\xrightarrow{A_{code}}R_{t+1}$$
你CodeGen
海水、岩面、身体repo、tests、tools
感觉状态typed context
触腕动作patch + command
位移与压力变化compiler + test + runtime
$$\begin{array}{ccc}\text{text}&\xrightarrow{G}&\text{code}\\ \downarrow P&&\downarrow W\\ \text{context}&\xrightarrow{A}&\text{repo}\end{array}\qquad W\circ G\approx A\circ P$$

EnvFeedback 成功：图交换

目标变化记作 g。你稳稳接触岩面；CodeGen 通过测试。

$$\begin{array}{ccc}E_t&\xrightarrow{P}&S_t\\ &\searrow_{g}&\downarrow A\\ &&E_{t+1}\end{array}\qquad A\circ P\approx g$$

成功保留三项：所需上下文、有效动作、验证条件。不要记忆整份 patch。

EnvFeedback 失败：图不交换

$$A\circ P\not\approx g$$
signalbroken maprevision
状态缺失P补 context
patch 不可应用adapter修边界
行为不满足A改生成
测试不稳定feedback修环境

按来源拆分 stderr。一次只修改一条边，再运行同一反例。

具身进化：更新闭环

$$E_t\xrightarrow{P_t}S_t\xrightarrow{A_t}E_{t+1}\xrightarrow{F}O_t\xrightarrow{R}(P,A)_{t+1}$$

你根据反馈调整感觉与动作。Coding agent 对应更新 context、工具策略、工具边界与记忆检索。

$$T:(E,K)\to(E,K),\qquad T^{n+1}=T\circ T^n$$

K 是持续更新的 agent 状态。R 改变下一轮 P 或 A，Reflect 才改变系统。

追求下一次交换图更接近交换，不追求单次生成更聪明。
